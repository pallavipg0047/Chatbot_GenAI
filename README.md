# Chatbot_GenAI

A Generative AI–powered chatbot built with Python and Streamlit, designed for **document summarization** and **contextual Q&A**.  
This project leverages Retrieval-Augmented Generation (RAG) to provide accurate, human‑like responses based on uploaded documents or knowledge sources.

---

## 🚀 Features
- **Document Summarization**: Upload PDFs and get concise summaries.
- **Contextual Chat**: Ask questions about your documents and receive AI‑generated answers.
- **Streamlit UI**: Simple web interface for interaction.
- **Secure API Integration**: Uses OpenAI API with `.env` for key management.
- **Extensible**: Easily add new models or data sources.

---

## 🛠️ Tech Stack
- **Python 3.14+**
- **Streamlit** (for UI)
- **OpenAI API** (LLMs for summarization & chat)
- **LangChain / FAISS** (for RAG document retrieval)
- **Virtual Environment** (`.venv`)
